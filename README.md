## 🛠️ Architecture & Tech Stack

- **Framework**: React 19 + Vite + TypeScript (Strict Mode)
- **Styling**: Tailwind CSS + Custom Obsidian Noir & Platinum Palette
- **Animation**: Framer Motion (3D Spring Tilt Physics, LayoutId active pills, Staggered Reveals)
- **Icons**: Lucide React
- **Compute & Audio**: Web Audio API (real-time harmonic synthesis), WebAssembly (WASM), Canvas API
- **Responsive**: 100% responsive across all viewports ($375\text{ px}$, $390\text{ px}$, $768\text{ px}$, $1440\text{ px}+$) with zero horizontal overflow

## 🚀 Getting Started

```bash
# Clone repository
git clone https://github.com/yankun22/alokvishwa-studio.git
cd alokvishwa-studio

# Install dependencies
npm install

# Run development server
npm run dev

# Build production bundle
npm run build
```
